Fragenkonfigurator

Erstelle individuelle Fragen und ordne sie passenden Themen zu. Ob für die persönliche Vorbereitung oder als Teil eines größeren Fragenpools – der Fragenkonfigurator bietet volle Flexibilität.

Unterstützt werden verschiedene Fragetypen wie Single-Choice, Multiple-Choice, Bildfragen und Freitextfragen.
